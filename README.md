# ChikondiCare Hospital Management System

A web-based Hospital Management System designed to simplify and improve hospital operations by managing patients, doctors, appointments, consultations, prescriptions, payments and reports in one centralised platform.

## About the Project

ChikondiCare is a hospital management system developed as part of **Web Programming Assignment 1**. The system aims to reduce manual record keeping, improve information management and make hospital workflows more efficient.

The application is being developed using Laravel, SQLite and Tailwind CSS.

## Features

### 1. User Authentication and Administration
- Secure user login and logout.
- Role-Based Access Control (RBAC).
- User and staff account management.
- Doctor management.
- Medicine catalogue management.
- Consultation fee management.
- System activity and audit logs.

### 2. Patient Management
- Register new patients.
- Generate unique patient identification numbers.
- Manage patient personal and contact information.
- Record next-of-kin information.
- Assign primary doctors.
- Search, view and update patient records.
- Manage patient check-in.

### 3. Appointment Management
- Book patient appointments.
- Manage doctor availability and schedules.
- Support full-time and visiting doctors.
- Prevent double booking.
- Cancel appointments and record cancellation reasons.
- Search and filter appointments.
- Generate appointment confirmations.

### 4. Consultation Management
- View checked-in patients.
- Record patient diagnoses.
- Add consultation notes.
- Maintain consultation history.

### 5. Prescription Management
- Create patient prescriptions.
- Record prescribed medicines.
- Specify dosage, frequency and duration.
- Maintain prescription history.

### 6. Payment Management
- Record patient payments.
- Generate unique transaction and receipt numbers.
- Generate printable PDF receipts.
- Search and filter payment records.

### 7. Reports
- Daily appointment reports.
- Patient reports.
- Revenue reports.
- Visiting doctor schedules.
- Prescription and payment records.
